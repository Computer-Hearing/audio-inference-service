# Audio Traffic Classification

Система для multi-task классификации городских акустических событий.

---
## Цель  
 
Разрабатывается устройство, которое будет слышать по примеру человеческого слуха и транслировать эту информацию в другие системы беспилотного автомобиля для более адекватного восприятия реальности и окружающей обстановки вокруг автомобиля.  

Цель проекта: разработать систему компьютерного слуха для классификации городского транспорта на основе искусственного интеллекта.  

## Задача

Multi-task классификация звуков дорожного трафика:

1. **Тип транспорта** (5 классов):
   - car
   - emv (спецтранспорт)
   - motorcycle
   - tram
   - truck
2. **Характер движения** (7 классов):
   - acceleration
   - bell
   - braking
   - horn
   - idling
   - passing
   - siren

Обе задачи решаются одновременно на основе одного входного аудиосигнала.

-

## Данные

- **Формат:** WAV, моно
- **Количество файлов:** 6 281

---

**Анализ:**
- CNN показывает наилучший баланс между качеством и скоростью, уступая LSTM по Vehicle Accuracy на 0.8% и превосходя по Action Accuracy на 1%
- LSTM демонстрирует максимальную точность распознавания категории автомобиля (97.8%), но требует больше времени и имеет в 4 раза больше параметров, чем RNN
- RNN — самая лёгкая модель с минимальным числом параметров (166K), однако заметно уступает по качеству классификации типа движения

## Архитектуры

### CNN - бейзлайн
Архитектура:
- Вход: мел-спектрограмма размером 256 × 173 (1 канал)
- Пять свёрточных слоёв с увеличением числа каналов: 32 → 64 → 128 → 256 → 256
- После каждого свёрточного слоя: ReLU и MaxPool2d с ядром 2 для уменьшения пространственной размерности
- Итоговый размер признакового пространства: 256 × 16 × 10
- Flatten и Dropout(0.5)
- Две полносвязные головы: каждая содержит слой 4096 → 128 → выход (5 или 7 классов)

Обоснование:
- CNN выбрана как классическая архитектура для обработки спектрограмм, эффективно выделяющая локальные частотно-временные паттерны  
- Увеличение числа каналов (32 → 256) позволяет на каждом уровне извлекать всё более сложные акустические признаки: от простых тонов до сложных тембральных характеристик автомобиля  
- MaxPooling уменьшает размерность в 16 раз, сохраняя наиболее значимые признаки и обеспечивая инвариантность к небольшим сдвигам во времени и частоте  
- Глубина в 5 слоёв достаточна для захвата релевантных признаков при размере спектрограммы 256×173, без риска переобучения на ограниченном датасете  
- Раздельные головы с промежуточным слоем 128 нейронов позволяют адаптировать общие спектральные признаки под каждую классификационную задачу  
- Dropout(0.5) перед полносвязными слоями предотвращает переобучение, характерное для свёрточных сетей с большим числом параметров  

### RNN
Архитектура:

- Два рекуррентных слоя с размерностями 128 и 64 нейронов  
- Пакетная нормализация после каждого слоя  
- Dropout и recurrent_dropout для регуляризации  
- Полносвязный слой на 64 нейрона  
- Две выходные головы: для категории авто и типа движения  

Обоснование:
- RNN выбрана как архитектура, предназначенная для работы с последовательностями. Входной аудиосигнал длительностью 2 секунды преобразуется эмбеддером YAMNet в последовательность из 4 векторов размерностью 1024, что позволяет модели обрабатывать временную динамику звука  
- Два рекуррентных слоя с каскадным уменьшением размерности (128 → 64) позволяют извлекать временные паттерны на разных уровнях абстракции  
- Пакетная нормализация после каждого слоя стабилизирует обучение  
- Dropout защищают от переобучения на малом датасете  
- Раздельные выходные головы позволяют адаптировать веса для каждой задачи независимо  

---

### LSTM
Архитектура:
- Полностью повторяет структуру RNN с заменой на LSTM

Обоснование:
- Идентичная архитектура обеспечивает честное сравнение двух типов рекуррентных ячеек  
- LSTM эффективнее фильтрует шумовые компоненты внутри каждого кадра благодаря механизму гейтов  
- Пакетная нормализация после каждого слоя компенсирует проблемы с затухающими градиентами

## Модели и эксперименты

Все эксперименты проводились в Google Colab с графическим ускорителем NVIDIA T4. Замеры времени инференса производились с усреднением по 100 запускам после прогрева модели. Для воспроизводимости использовался фиксированный seed.

### Сравнительная таблица

| Модель | Vehicle Accuracy (%) | Action Accuracy (%) | Параметры | Время инференса (мс) |
|--------|---------------------|---------------------|-----------|---------------------|
| CNN | 97.0 | 88.0 | 11 млн | 0.57 |
| RNN | 96.4 | 82.9 | 166K | 7.85* |
| LSTM | 97.8 | 87.0 | 645K | 9.44* |

\* Для RNN и LSTM указано полное время инференса, включающее YAMNet (7.05 мс) и рекуррентную модель (RNN — 0.80 мс, LSTM — 2.39 мс)
